# ILMB Paralysis End-to-End v1.0

Paralysis is modeled as a phenotype, not as one disease.

## Governing architecture
`PAR-CORE` contains the universal motor chain, emergency gates, localization,
measurements, formula governance, provenance, rehabilitation logic and reporting.
Each causal mechanism has a separate module.

## Safety boundary
New or worsening sudden focal weakness, rapidly ascending weakness,
respiratory/swallowing weakness, or suspected acute spinal compression bypasses
routine restoration logic and enters urgent medical evaluation.

## Math boundary
No fitted treatment-effect coefficient is included. Current formulas are
physical identities, arithmetic longitudinal measures, or clearly labeled
structural frameworks.
