# Phase 120 — Psoriasis Final Discovery Conclusion

## Source basis

This conclusion freezes the convergence between the independently derived ILMB psoriasis formula stack and the verification-only workbook `ILMB_Psoriasis_Genuine_Discovery_Program_v1.8`.

The workbook's `51_VERIFIED_CONCLUSION` sheet states that psoriasis is a coupled immune–epidermal–barrier system with upstream modifiers and that the common therapeutic target is stable epidermal–immune homeostasis. Its `50_PATTERN_DISCOVERY` sheet identifies three principal therapeutic convergence zones: immune drive, epidermal proliferation/differentiation, and barrier/lesion output. Its `54_DECISION_RULES` sheet explicitly blocks mechanistic claims when only outcomes are observed. Phase 120 preserves those boundaries.

## Final conclusion

**Psoriasis is best represented as a fixed-susceptibility, dynamically modifiable immune–epidermal–barrier system.** The common treatment target is not one drug, one cytokine, or one named alternative modality; it is restoration of compartment-resolved epidermal homeostasis with control of the coupled immune loop and normalization of barrier/lesion geometry.

The physical endpoint remains:

`V_excess = A_lesion * max(h_epi - h_normal, 0)`

A successful pathway must produce:

`dV_excess/dt < 0`

until `V_excess -> 0`, `h_epi -> h_normal`, and barrier state approaches the matched physiological state.

## Non-drug conclusion

The strongest established direct non-drug reference path is **controlled phototherapy / NB-UVB**. The full non-drug architecture is layered rather than a one-for-one drug replacement:

1. direct skin/immune modulation — reference: controlled NB-UVB;
2. barrier restoration — direct downstream support;
3. metabolic correction — only when a measured abnormality/eligible subgroup exists;
4. stress/autonomic correction — supported upstream modifier when measured;
5. research adjuncts — EMDR, acupuncture, named botanicals/formulas only when exact exposure and mediator are measured;
6. verification/narrative layers — homeopathy, Bach, Louise Hay, Redikall, unless independently upgraded by biological measurements.

## What is not concluded

- Genetics are not irrelevant.
- IL-17 is not irrelevant.
- Similar PASI responses do not imply identical mechanisms.
- A positive outcome trial does not prove the source system's proposed mechanism.
- PASI75/90/100 does not prove cure.
- No universal alternate cure has been established.

## Discovery rule

Every proposed modality is evaluated as:

`U -> measured node change -> compartment change -> lesion regression -> durability`

Mechanistic upgrade requires temporal order, direct mediator measurement, replication and confound control.
