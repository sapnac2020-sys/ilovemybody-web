# Psoriasis Prospective Execution v1

Status: research execution framework; not a universal prescription or cure claim.

## Objective

Test whether the governed candidate non-drug treatment pattern produces objective lesion regression, measurable node change, and durable improvement.

## Candidate layers

1. Direct control: NB-UVB/controlled phototherapy when appropriate.
2. Barrier repair: site-specific barrier care.
3. Amplifier removal: only measured/reproducible triggers or metabolic abnormalities.
4. Upstream regulation: stress/autonomic/sleep correction when measured.
5. Research adjuncts: EMDR/acupuncture tracked separately; homeopathy/Bach/Louise Hay/Redikall remain verification/narrative layers unless independently mechanistically validated.

## Mandatory sequence

Safety + phenotype -> baseline -> measured exposure -> early objective direction -> mid-course node check -> clearance/normalization assessment -> durability/time-to-relapse.

## Primary mathematical endpoint

V_excess = A_lesion * max(h_epi - h_normal, 0)

Candidate lesion regression requires:

dV_excess/dt < 0

Candidate normalization requires:

V_excess -> 0, h_epi -> h_normal, and barrier state -> matched physiological state.

## Evidence upgrade rule

An outcome is not a mechanism. Mechanistic upgrade requires:

intervention -> measured node change -> compartment change -> lesion regression -> correct temporal order -> replication/confound control.

## Durability

T_R = t_relapse - t_best_response

PASI75/90/100 or temporary plaque clearance does not by itself establish cure. Time to relapse is an independent required endpoint.

## Safety

Urgent red flags, generalized pustular psoriasis, erythrodermic psoriasis, serious infection, or other acute safety blocks override the research protocol and require appropriate urgent medical assessment.
